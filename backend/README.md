# Campus Lost and Found Portal
A full-stack web application that helps students report, search, and claim lost and found items on campus.

## Features

- Student registration and login
- JWT-based authentication
- Report lost and found items
- Browse and search reported items
- Filter items by type
- View personal reported items
- Submit and track claims
- Admin claim management
- Admin item management
- Approve and reject claims
- Delete inappropriate item reports

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman

## Project Structure

- `frontend/` – User interface
- `backend/` – Server, routes, models and database connection

## How to Run

1. Install Node.js.
2. Open the backend folder in the terminal.
3. Install dependencies using `npm install`.
4. Configure your MongoDB connection and JWT secret in the backend `.env` file.
5. Start the server using `npm run dev`.
6. Open the frontend using VS Code Live Server.

## API Testing

Postman was used to test the application's REST APIs. The Postman collection is included in this repository.
